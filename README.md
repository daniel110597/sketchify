# sketchify
Photo to Sketch Converter A web application that converts photos into artistic sketches using OpenCV and Flask. Supports multiple styles like pencil, charcoal, ink, watercolor, and oil painting.  You can also add:  Features: Live preview, multiple sketch styles, and easy-to-use UI.  Tech Stack: Python, Flask, OpenCV, HTML, CSS, JavaScript.
